How a scan works

  1. You select one or more files on the scan page.
  2. Each file is saved into the uploads folder with a safe name.
  3. The file is read in 4096-byte blocks and a SHA-256 hash is built.
  4. That hash is compared with the known-malicious hash list.
  5. The result is shown on screen and saved in the scan history.

This is a basic hash-based antivirus scanner built as a student project. It detects only malware whose exact hash is already in the list. A result of Safe means no known-malicious hash matched, not that the file is guaranteed virus free.
